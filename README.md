# 🧰 Python Scripts

This repository contains several independent Python scripts and utilities created throughout my learning journey.

Some scripts are from my early stages of learning (basic syntax, loops, file handling), while others are more structured projects such as the **Time Calculator**, which demonstrates modular design and command-line interaction.

---

## 🧩 Repository Overview

| Script / Folder | Description |
|-----------------|--------------|
| `time-calculator/` | CLI tool for adding or subtracting time intervals. |
| `find-files.py` | Searches for files in a directory and logs results to a `.log` file. |
| `find_number.py` | Simple number finder and validator. |
| `google-images-downloader.py` | Downloads images automatically from Google results (practice in automation and APIs). |
| `digito_verificador-patentes.py` | Utility for validating vehicle license digits (Argentina). |
| `stuff.py` | Experimental file, nothing of added value on this one. |
